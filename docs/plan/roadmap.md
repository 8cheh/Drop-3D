## 1. 任务定义

**一句话**：从液滴图像（含滚动的动态场景）可靠地给出界面性质，并在方法失效时**拒绝作答**。

### 1.1 交付物

| 编号 | 交付物 | 形式 |
|---|---|---|
| D1 | 悬滴法表面张力 | `drop3d.tensiometry` + 拟合器 |
| D2 | 固体表面自由能 | `drop3d.surface_energy` |
| D3 | 不确定度量化 | `drop3d.uncertainty` |
| D4 | 分布外拒绝 / 适用域判定 | `drop3d.validity` |
| D5 | 动态与滚动液滴的可用测量集 | `docs/research/` 结论 + 代码支持 |
| D6 | 可复现的验证 | `tests/` + CI |

### 1.2 明确的边界（本任务**不**做）

- 不做液滴的三维重建本体（那是仓库里其他任务的事，我们只消费二维轮廓）；
- 不做相机标定硬件驱动；
- 不训练大模型。若最终引入 ML，只用于 D4 的辅助判据，且必须能退化为纯物理判据。

| 项 | 内容 | 状态 |

**调研结论（比原估计更严重）**：模型间差异不是 5–15 mJ/m²，文献报告**60–130%**。
更麻烦的是**探测液体的参数本身就分歧很大**——二碘甲烷的色散分量在文献中
横跨 **44.1–50.8 mN/m**（13%），而它是几乎所有拟合里锚定 γ_s^d 的那个。

因此 `PROBE_LIQUIDS` 的每个参数都带出处，并且**不允许跨来源混用参数集**。
另有一项常被忽略的系统误差：Young 方程里是 γ_sv 而非 γ_s，
**忽略扩散压会单方向低估** γ_s（对聚合物可忽略，对金属/氧化物/玻璃/等离子处理表面显著）。

### W3 — 不确定度量化 ✅ 已实现，覆盖性已检验

| 项 | 内容 | 状态 |
|---|---|---|
| W3.1 | 拟合参数的协方差估计 | ✅ **已修正**：残差相关性用 Newey–West sandwich 处理 |
| W3.2 | 从参数协方差传播到 γ（GUM） | ✅ 已实现 |
| W3.3 | Monte Carlo 传播（含尺度、密度等系统项） | ✅ 已实现 |
| W3.4 | 覆盖性检验（报 95% 是否真的覆盖 95%） | ✅ 已实现 |

**已修正的缺陷**：`σ²(JᵀJ)⁻¹` 假设残差独立同分布，
而几何拟合的残差是**到曲线的距离，天然相关**，因此方差被**低估**。
现默认用 Newey–West sandwich，并**实测**了效果：

| 残差 | naive | HAC |
|---|---|---|
| 独立同分布 | 0.89 | **0.95** |
| 相关（L≈5） | **1.93** | **1.21** |

（经验值/预测值，1.0 为正确）线性模型的**精确**判据下，
相关越强 HAC 越吃力：ρ = 0.8 恢复 56%，ρ = 0.95 恢复 27%。

**已知局限（不粉饰）**：强相关下 HAC 仍偏低。
`parameter_covariance` 在 ρ̂ > 0.5 时**会在返回值里自曝这一点**并指明改用
bootstrap / Monte Carlo。完整证据见
[`docs/validation/hac-covariance.md`](../validation/hac-covariance.md)。

**主误差项有出处了**：Loglio et al., *JCIS* **265** (2003) 161 ——
标定误差同时影响两轴时表面张力出现**平方**误差，且 **x/y 两轴标定不一致时
结果「明确不可靠」**。故两轴须独立标定并验证一致。
另：自由度为 1–4 时须用 Welch–Satterthwaite（t 因子 4.30/3.18，直接报 ±2SE 会差 1.5–2 倍）。

### W4 — 分布外拒绝 / 适用域 ✅ 核心已实现

| 项 | 内容 | 状态 |
|---|---|---|
| W4.1 | 残差类判据（RMS、游程检验） | ✅ 已实现 |
| W4.2 | 几何有效性判据（轴对称性、倾斜、轮廓范围） | ✅ 已实现 |
| W4.3 | 条件数判据 | ✅ **Wo 两级闸门**为主，P_s 次之 |
| W4.4 | 数值收敛与解分支校验 | ✅ 已并入 Wo 闸门 |
| W4.5 | 统一裁决层：多判据 → 可解释理由 + 命名错误码 | ✅ 已实现 |
| W4.6 | 共形区间 + **按区间宽度拒绝** | ✅ 已实现（`drop3d.conformal`） |

**调研推翻了原设计**：原计划以 **Bond 数**为主要条件数判据，
但文献明确指出 **Bo 不能预测精度**（小体积下失效，Yang, Yu & Zuo 2017）。
现改为：**Bo 仅作求解器有效性检查**（超出范围前向模型本身无意义），
**精度由 Worthington 数把关** —— `Wo = 0.5` 是形状方程分叉边界
（Kratz & Kierfeld 2020），低于它多个解支共存，拟合可能收敛到错支；
`Wo > 0.1` 是工作阈值。

术语上采用 **applicability domain**（QSAR/OECD 原则三）而非 ML 语境的 OOD，
并且**刻意不做单一标量分数**，改为五类独立闸门 + 计数式可靠性分级。

**未解决**：Ne 的数值阈值**没有文献依据**，代码中标注为占位值（`engineering`），
须用标准液体标定。**文献中不存在「低于某 Bo 就拒绝」的阈值表**，
任何 Bo 下限必须来自我们自己的标定。

**新的实测发现：形状参数 P_s 在 Bo ≈ 0.45 达峰后下降**，不是单调的
（0.3332 @ Bo 0.30 → **0.4379 @ 0.45** → 0.2427 @ 0.60）。
物理原因是过了某个形变程度子午线就不再闭合于轴、轮廓趋向柱状。

**这条有实际后果**：有效性闸门只有 P_s 的**下限**（0.15），
所以在 Bo ∈ (0.45, 0.6) 这一段，闸门其实比在 0.45 处**更难通过**，
而液滴实际上形变更大——是**保守方向的偏差**，不会放行坏数据，
但会让实验者困惑。而且它意味着**「换更大的液滴」不是永远有效的建议**，
这正是 `drop3d-ps` 默认只扫到峰值的原因。

**W4.6 已实现——共形预测区间**（`drop3d.conformal`，20 项测试）。
这是本库唯一**不假设任何东西**的不确定度路径：给定标定集与水平 `1−α`，
区间以至少 `1−α` 的概率包含真值，**与模型好坏无关**。
而 YL 拟合在真实图像上必然是设定错误的模型，所以这条性质正合适。

- **标定量下限已实测并强制**：95% 需要 **≥19** 个标定点，99% 需要 99 个。
  低于此返回 `inf` 而不是一个「看起来像数」的数。
- **分割共形是保守的**：可达水平是 `⌈(n+1)(1−α)⌉/(n+1) ≥ 1−α`，
  所以接口返回 `level_achieved`；实测覆盖率与之吻合到 0.001。
- **Mondrian 按 Wo 分箱是必需的，不是优化**：实测边缘区间总体覆盖率 0.950，
  但**低 Wo 箱只有 0.690**、高 Wo 箱过度覆盖到 0.997。
  低 Wo 正是物理闸门已判定拟合退化的区间——**在那里悄悄只覆盖 69%
  却声称 95% 是最糟的失效方式**。分箱后三箱分别为 0.985 / 0.967 / 0.964。
- **可交换性被检验而非假设**：破坏后覆盖率从 0.95 掉到 0.46，
  KS 检验每次都发现。调研明确指出「用静态悬滴标定后喂滚动液滴会破坏可交换性」，
  这是该风险的可执行版本。
- **宽度容忍度必填无默认**：2 mN/m 是否可接受取决于用途，
  放默认值等于把我们的方便伪装成要求。

完整证据见 [`docs/validation/conformal-intervals.md`](../validation/conformal-intervals.md)。

**W5.1 的答案**（[ADR-0002](../decisions/0002-axisymmetric-vs-non-axisymmetric.md)）：
问题必须拆成两半。

- **振荡/脉动悬滴**：每帧仍是轴对称悬滴，**同一求解器逐帧跑**即可，动态增量很小。
  但**必须拟合仪器相位滞后**——已发表工作不加滞后项时拟合出了**负的**振幅。
- **滚动/滑移液滴**：轴对称 YL 拟合**前提失效，不能用**。
  证据：商业 YL 软件在液滴被扰动后直接拒绝出值；最先进的滑移液滴论文
  （Vieira et al., *Langmuir* **40**(17) 2024, 9059）彻底放弃 YL，
  改用 Surface Evolver 三维有限元、以**实测接触线为边界条件**；
  且滑移液滴的足迹是椭圆，**即使在均匀表面上 L/W 也有 1.011–1.097**。

故架构拆为 **Module A（轴对称）→ Module B（非轴对称）**，依赖单向。
Module B **永不**在轮廓上调用 YL 拟合器，γ 作为**输入**。

**W5.2 已实现**（`drop3d.dynamics`，35 项测试）：

- **Furmidge 保持力**，几何前因子 `k` **显式可调**，并且**默认值不是 1**——
  `k = 1` 假设接触线处接触角**间断**，而该模型在 `t = π` 与 `t = 2π` 两处间断，
  物理上不成立。默认取已发表的**分段线性**模型 `k = 2/π`，
  并且**每次调用都返回**在物理容许区间 `[0.5, 0.884]` 上的力**范围**而非单点。
- **Dunlop 精确力平衡**：给定实测的 `θ(φ)`，用 Fourier 系数直接得到重力驱动项，
  **完全不需要 `k`**。这是消除 `k` 歧义的推荐路径。
- **Cox–Voinov 动态接触角**（前进/后退两支）。`ln(b/a)` **设为必填**——
  报告只给了关系式没给这个值，给个默认值等于替用户偷偷选了微观截断尺度。
- **两种坡度 Bond 数约定**显式区分（相差约 **2.6 倍**），必须具名传入。
  这与求解器用的 `Bo = ΔρgR₀²/γ` **不是同一个量**，只是同名。
- 足迹纵横比，带**均匀表面的基线区间**（避免把 1.05 误读成表面不均一）。

**足迹几何已实现**（`drop3d.fitting.fit_ellipse`，18 项测试）：

- 椭圆拟合**无噪数据精确到机器精度**（1e-14）。实测 aspect 精度在 0.3 px 噪声下
  为 ±0.0006——足以分辨 `L/W = 1.011` 与 `1.000`（约 18σ），而均匀表面带只有 0.086 宽。
- **弃用了教科书做法**：经典圆锥曲线拟合在**理想数据上是奇异的**
  （点精确落在椭圆上时 `x², y², 1` 三列线性相关，实测最小奇异值恰为 0）。
  改为几何距离的多起点 Gauss–Newton。- **闸门落在数据的直接属性上**：接触线**角度跨度 ≥ 230°**（实测值）才报 `L/W`。
  实测 240° 及以上 bias < 0.001 且**跨平台可复现**；240° 以下不行
  （150° 弧在同一个 numpy 版本上本机给 +0.004、CI 给 **−0.030**，
  而 0.030 是 0.086 带宽的三分之一）。

> ⚠️ **两次更正（同日第八轮）**：
> 1. 本轮早些时候这里写过「部分接触线根本不可辨识，200° 弧会拟合出 aspect 2.05」。
>    **那是错的**——真正原因是**单起点优化落进局部极小**，

>    本机与 CI 结果差 0.030。所以标准不是「有时准」而是「可复现地准」，
>    下限提到 240°。
>
> 保留这两条记录，因为「把优化器缺陷当成物理局限」是一个**会被写进文档
> 并且看起来很严谨**的错误。详见
> [`docs/validation/ellipse-footprint.md`](../validation/ellipse-footprint.md)。

**故意没实现**：Dussan 起动临界 Bond 数。转抄的公式在报告自带表格的三行上算出
0.816 / 1.026 / 1.071，而表中写的是 0.14 / 0.28 / 0.32，**比值非常数**
（5.83 / 3.67 / 3.35），所以不是归一化差异而是式子本身不对。

**W5.5 已实现**（`drop3d.oscillation`，23 项测试）：

振荡/脉动悬滴的**逐帧 YL 拟合本身不变**（每帧仍是轴对称悬滴，同一个求解器），
新增的只是时域分析。链路：逐帧 → `γ(t)`, `A(t)` → 正弦拟合 →
`A₀, A_a, γ₀, γ_a, δ` → `E′ = E cos δ`, `E″ = E sin δ`。

**调研点名的那个坑已复现并量化**：仪器相位滞后**必须拟合**，
所以 `φ_ins` 是**两条序列共享的拟合参数**，不是假设。
实测注入滞后 0°–150° 时往返**精确到机器精度**；
去掉滞后项则该滞后被 `δ` 吸收、**面积振幅塌缩到 0**、模量炸到 1.8×10⁷。

> 注意：调研说「会得到负振幅」。**实测只在滞后很大（≥150°）
> 且拟合未加正性约束时才出现负振幅**；我们发布的实现有正性约束，
> 所以失败形态是「数值巨大但看起来正常」——**比负号更危险**。
> 因此该开关会主动警告，而不是依赖符号暴露问题。
> 详见 [`docs/validation/oscillation-phase-lag.md`](../validation/oscillation-phase-lag.md)。

采样率：调研给的是相机规格（1 Hz 下 750 fps）与工程规则（≥100 帧/周期），
并明确标注文献中**没有**最低采样比的规定。已实测：100 帧/周期对应
E 误差约 **0.68%**，25 帧/周期约 1.2%，**规则偏保守、约留 2 倍余量**。
误差条经覆盖性检验（报出标准误/实际散布 = 0.79–1.17）。

**未实现**：振荡频率上限。Cagna et al. 有专文，但调研未取得其数值，
故**不引用任何截止频率**。

**W5.3 / W5.6 已实现——采集风险闸门**（`drop3d.hazards`，20 项测试）。
这是调研自己的建议第 7 条：「加一个『动态模式』警告面板」。
它的价值在于**把失效模式在使用者还能改实验的时候摆到他面前**，
而不是埋在报告里。

三条设计规则：

1. **本模块不发明任何阈值。** 每个数字都带出处标签：
   文献写了值的标 `literature`；由公开界推出来的标 `engineering`
   **并写明从哪条界推的**。
   有一条采样比**文献里根本没有**，模块就明说「没有出处」而不是当成引用。
2. **风险分等级，不是只有「有/无」。** `blocking` = 该分析无法支撑它的结论；
   `serious` = 结果很可能有偏，必须与偏差一起报告；`advisory` = 报告即可。
   **一份不分级的警告清单会训练人把所有警告都忽略。**
3. **最危险的是没有症状的那条。** 混叠的钉扎不表现为错误，
   而表现为「数据点缺失」；相位滞后不表现为错误，
   而表现为「负的模量」或「塌缩的面积振幅」。
   这两条都在使用者还能补救的位置被明确点出。

覆盖的场景与门槛（全部有出处）：振荡 ≥100 帧/周期（工程规则，
文献点 1 Hz 下 750 fps）、滑移几何 100 fps（文献）、
接触线动力学 ≥1 kHz（由「解钉 <10 ms」这条**公开界**推出，
100 fps 会把它混叠掉）、撞击 4000–15000 fps（文献）；
空间 1–15 µm/px，接触线工作 0.7 µm/px（文献）。

另外**永久性**点出三条滑移侧注意事项：滚落角**不是材料常数**
（文献明说高度依赖液滴尺寸与倾角速率）、
足迹即使在均匀表面上也是椭圆（L/W 1.011–1.097，**不能**读成不均一）、
以及 γ 在这里是**输入**不是输出。

**仍需团队回答**：四种动态场景（滑落 / 滚动 / 剪切驱动 / 撞击铺展）**是哪一种**，
仍直接决定 Module B 剩余部分的设计。

## 6. 需要团队决策的事项

1. **许可证** —— ADR-0001，最高优先级。
   注：开源生态里成熟实现几乎全是 **GPL-3.0**（含 OpenDrop），
   若我们要宽松许可则不能抄它们；ADR-0001 推荐 Apache-2.0。
2. **动态场景的实际形态** —— 是哪一种？
   - 液滴在斜面上滑落
   - 液滴在表面上滚动（超疏水）
   - 液滴被气流/剪切驱动
   - 液滴撞击表面后的铺展

   这四种的物理与可用测量差别很大，直接决定 Module B 的设计。
   *（注：ADR-0002 已经解决了「动态下 YL 假设是否成立」这个更上位的问题，
   但没有、也无法替代本条——上面四种场景都需要 Module B，而 Module B 内部
   需要知道是哪一种。）*
3. **精度目标** —— 表面张力 <1% 还是 <3%？直接决定硬件规格与是否需要真实数据标定。
   参考：文献报告的实验室间复现性很差，±1–2°（接触角）之类的数字是**实验室内重复散度**，
   不是实验室间复现性。
4. **是否有可用的实验条件** —— 谁能提供悬滴与滚动液滴的图像？
   这是目前**唯一**卡住 M1/M2 真正结题的因素。
5. **探测液体参数集的选用** —— 二碘甲烷的 γ^d 在文献中横跨 44.1–50.8 mN/m，
   必须指定一套并全库统一，否则表面自由能的误差条毫无意义。
