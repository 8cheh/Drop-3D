> 建立日期：2026-09-16 　维护人：HPIline 　状态：**active**

---

## 1. 任务定义

**一句话**：从液滴图像（含滚动的动态场景）可靠地给出界面性质，并在方法失效时**拒绝作答**。

### 1.1 交付物

| 编号 | 交付物 | 形式 |
|---|---|---|
| D1 | 悬滴法表面张力 | `drop3d.tensiometry` + 拟合器 |
| D2 | 固体表面自由能 | `drop3d.surface_energy` |
| D3 | 不确定度量化 | `drop3d.uncertainty` |
| D4 | 分布外拒绝 / 适用域判定 | `drop3d.validity` |
| D5 | 动态与滚动液滴的可用测量集 | `docs/research/` 结论 + 代码支持 |
| D6 | 可复现的验证 | `tests/` + CI |

### 1.2 明确的边界（本任务**不**做）

- 不做液滴的三维重建本体（那是仓库里其他任务的事，我们只消费二维轮廓）；
- 不做相机标定硬件驱动；
- 不训练大模型。若最终引入 ML，只用于 D4 的辅助判据，且必须能退化为纯物理判据。

### W2 — 固体表面自由能 ✅ 已实现，待真实数据验证

| 项 | 内容 | 状态 |
|---|---|---|
| W2.1 | OWRK / Wu / Fowkes / 酸碱 / Zisman 实现 | ✅ 已实现 |
| W2.2 | 探测液体参数库（带出处与不确定度） | ✅ 已实现，⚠️ 参数分歧见下 |
| W2.3 | 模型间差异的量化与报告 | ✅ `compare_models` / `recommend` |

**调研结论（比原估计更严重）**：模型间差异不是 5–15 mJ/m²，文献报告**60–130%**。
更麻烦的是**探测液体的参数本身就分歧很大**——二碘甲烷的色散分量在文献中
横跨 **44.1–50.8 mN/m**（13%），而它是几乎所有拟合里锚定 γ_s^d 的那个。

因此 `PROBE_LIQUIDS` 的每个参数都带出处，并且**不允许跨来源混用参数集**。
另有一项常被忽略的系统误差：Young 方程里是 γ_sv 而非 γ_s，
**忽略扩散压会单方向低估** γ_s（对聚合物可忽略，对金属/氧化物/玻璃/等离子处理表面显著）。

### W3 — 不确定度量化 ✅ 已实现，覆盖性已检验

| 项 | 内容 | 状态 |
|---|---|---|
| W3.1 | 拟合参数的协方差估计 | ✅ 已实现，⚠️ 已知低估，见下 |
| W3.2 | 从参数协方差传播到 γ（GUM） | ✅ 已实现 |
| W3.3 | Monte Carlo 传播（含尺度、密度等系统项） | ✅ 已实现 |
| W3.4 | 覆盖性检验（报 95% 是否真的覆盖 95%） | ✅ 已实现 |

**已知缺陷（未修）**：W3.1 的 `σ²(JᵀJ)⁻¹` 假设残差独立同分布，
而几何拟合的残差是**到曲线的距离，天然相关**，因此方差被**低估**。
标准解法是 sandwich 估计 `(XᵀX)⁻¹XᵀΣX(XᵀX)⁻¹` 或对拟合过程整体做蒙特卡洛。**列为本轮之后的首要修正。**

**主误差项有出处了**：Loglio et al., *JCIS* **265** (2003) 161 ——
标定误差同时影响两轴时表面张力出现**平方**误差，且 **x/y 两轴标定不一致时
结果「明确不可靠」**。故两轴须独立标定并验证一致。
另：自由度为 1–4 时须用 Welch–Satterthwaite（t 因子 4.30/3.18，直接报 ±2SE 会差 1.5–2 倍）。

### W4 — 分布外拒绝 / 适用域 ✅ 核心已实现

| 项 | 内容 | 状态 |
|---|---|---|
| W4.1 | 残差类判据（RMS、游程检验） | ✅ 已实现 |
| W4.2 | 几何有效性判据（轴对称性、倾斜、轮廓范围） | ✅ 已实现 |
| W4.3 | 条件数判据 | ✅ **Wo 两级闸门**为主，P_s 次之 |
| W4.4 | 数值收敛与解分支校验 | ✅ 已并入 Wo 闸门 |
| W4.5 | 统一裁决层：多判据 → 可解释理由 + 命名错误码 | ✅ 已实现 |

**调研推翻了原设计**：原计划以 **Bond 数**为主要条件数判据，
但文献明确指出 **Bo 不能预测精度**（小体积下失效，Yang, Yu & Zuo 2017）。
现改为：**Bo 仅作求解器有效性检查**（超出范围前向模型本身无意义），
**精度由 Worthington 数把关** —— `Wo = 0.5` 是形状方程分叉边界
（Kratz & Kierfeld 2020），低于它多个解支共存，拟合可能收敛到错支；
`Wo > 0.1` 是工作阈值。

术语上采用 **applicability domain**（QSAR/OECD 原则三）而非 ML 语境的 OOD，
并且**刻意不做单一标量分数**，改为五类独立闸门 + 计数式可靠性分级。

**未解决**：Ne 的数值阈值**没有文献依据**，代码中标注为占位值（`engineering`），
须用标准液体标定。**文献中不存在「低于某 Bo 就拒绝」的阈值表**，
任何 Bo 下限必须来自我们自己的标定。

### W5 — 动态与滚动液滴 🚧 物理结论已出，场景待定

| 项 | 内容 | 状态 |
|---|---|---|
| W5.1 | 判定哪些测量在动态下仍然有效 | ✅ **已完成** → ADR-0002 |
| W5.2 | 动态可用量：体积、速度、前/后接触角、接触线形状、纵横比 | 待办（Module B） |
| W5.3 | 动态场景下的有效性降级策略 | 待办 |
| W5.4 | 时序跟踪（同一液滴跨帧） | 待办 |

**W5.1 的答案**（[ADR-0002](../decisions/0002-axisymmetric-vs-non-axisymmetric.md)）：
问题必须拆成两半。

- **振荡/脉动悬滴**：每帧仍是轴对称悬滴，**同一求解器逐帧跑**即可，动态增量很小。
  但**必须拟合仪器相位滞后**——已发表工作不加滞后项时拟合出了**负的**振幅。
- **滚动/滑移液滴**：轴对称 YL 拟合**前提失效，不能用**。
  证据：商业 YL 软件在液滴被扰动后直接拒绝出值；最先进的滑移液滴论文
  （Vieira et al., *Langmuir* **40**(17) 2024, 9059）彻底放弃 YL，
  改用 Surface Evolver 三维有限元、以**实测接触线为边界条件**；
  且滑移液滴的足迹是椭圆，**即使在均匀表面上 L/W 也有 1.011–1.097**。

故架构拆为 **Module A（轴对称）→ Module B（非轴对称）**，依赖单向。
Module B **永不**在轮廓上调用 YL 拟合器，γ 作为**输入**。

**仍需团队回答**：四种动态场景（滑落 / 滚动 / 剪切驱动 / 撞击铺展）**是哪一种**，
仍直接决定 Module B 的设计。

## 4. 当前状态（2026-09-16）

### 已完成且经过验证

- Young-Laplace 求解器：`Bo = 0` 精确退化单位球（误差 < 1e-8）；
  独立交叉验证复现公开的 selected-plane 经验关系，`Bo = 0.05–0.40` 内误差 < 0.4%。
- 五参数拟合：无噪回环误差 < 0.5%，0.5 px 噪声下 < 15%，
  端到端 72.0 mN/m 合成水滴恢复误差 < 5%。
- P_s 形状参数诊断（数据驱动版与精确版一致到 ~2%）。
- 表面自由能五模型（OWRK/Fowkes/Wu/酸碱/Zisman）+ 模型间离散度报告。
- 不确定度：GUM 传播、Monte Carlo、bootstrap、Welch–Satterthwaite 自由度、覆盖性检验。
- 适用域：五类闸门 + 命名错误码 + 计数式可靠性分级，**66 项测试通过**。

## 6. 需要团队决策的事项

1. **许可证** —— ADR-0001，最高优先级。
   注：开源生态里成熟实现几乎全是 **GPL-3.0**（含 OpenDrop），
   若我们要宽松许可则不能抄它们；ADR-0001 推荐 Apache-2.0。
2. **动态场景的实际形态** —— 是哪一种？
   - 液滴在斜面上滑落
   - 液滴在表面上滚动（超疏水）
   - 液滴被气流/剪切驱动
   - 液滴撞击表面后的铺展

   这四种的物理与可用测量差别很大，直接决定 Module B 的设计。
   *（注：ADR-0002 已经解决了「动态下 YL 假设是否成立」这个更上位的问题，
   但没有、也无法替代本条——上面四种场景都需要 Module B，而 Module B 内部
   需要知道是哪一种。）*
3. **精度目标** —— 表面张力 <1% 还是 <3%？直接决定硬件规格与是否需要真实数据标定。
   参考：文献报告的实验室间复现性很差，±1–2°（接触角）之类的数字是**实验室内重复散度**，
   不是实验室间复现性。
4. **是否有可用的实验条件** —— 谁能提供悬滴与滚动液滴的图像？
   这是目前**唯一**卡住 M1/M2 真正结题的因素。
5. **探测液体参数集的选用** —— 二碘甲烷的 γ^d 在文献中横跨 44.1–50.8 mN/m，
   必须指定一套并全库统一，否则表面自由能的误差条毫无意义。
